# District 7 Ventures — Modern Web Platform Revamp

A high-performance, luxury web application revamp for **District 7 / D7 Ventures** (Kochi, Kerala). Built with **Next.js 14**, **React**, **Tailwind CSS**, and **Lucide Icons**.

## 🌟 The Revamp Vision

Transformed from a static GoDaddy site builder into an ultra-modern, immersive hospitality portal highlighting District 7's core culinary pillars and B2B advisory:

1. **District 7 Encore (Kadavanthra)**: Fine dining, Pan-Asian & South East Asian delicacies, molecular gastronomy, English High Tea, and late-night dining until 2:00 AM.
2. **District 7 Restro Cafe (Vyttila)**: Kochi's favorite late-night hangout (open until 3:00 AM), famous for Google's **#1 Reviewed Steaks in Kochi**, and the original **Commando & Dynamite Cheese Loaded Fries**.
3. **District 7 Dulce**: Authentic European patisserie, handcrafted French entremets, tarts, and custom tiered celebration cakes.
4. **D7 Hospitality Consultancy**: 360° concept-to-execution restaurant advisory covering 3D theme design, commercial kitchen fabrication, menu engineering, POS/KDS systems, licensing, and staff training.

---

## 🚀 Key Features

- **Interactive Culinary Explorer**:
  - Live filter by Venue (*Encore*, *Restro Cafe*, *Dulce*)
  - Category filters (*Signature Steaks*, *Pan-Asian*, *Loaded Fries & Burgers*, *Patisserie*, *High Tea & Drinks*)
  - Dietary toggles (*Vegetarian Only*, *Non-Vegetarian*, *All*)
  - Instant text search across ingredients and dishes
  - Direct 1-click WhatsApp order / inquiry per item
  - One-click downloads for official menus:
    - *Encore 2024 Menu (PDF)*
    - *Vyttila Resto Cafe Menu 2025 (PDF)*
    - *Dulce Cake Menu 2025 (PDF)*
- **Smart WhatsApp Table Reservation Engine**:
  - Modal booking system selecting venue, guests, date, time slots (including late-night 1:00 AM slots), and special occasions (Birthdays, Anniversaries, High Tea).
  - Generates pre-formatted WhatsApp reservations routed to `+91 7736 030 777`.
- **B2B Consultancy Advisory Hub**:
  - 6 service pillar cards with enterprise workflow breakdowns.
  - Interactive consultation request form.
- **Brand Story Timeline**:
  - Celebrates the brand's evolution from the 2014 Panampilly Nagar food truck to Kochi's premier multi-venue dining group.
- **Dual Location & Live Hours Bar**:
  - Dynamic status indicator for late-night service (Encore until 2 AM, Restro Cafe until 3 AM).
  - Contact links for Kadavanthra and Vyttila branches.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI Library**: React 18, Tailwind CSS
- **Typography**: Cormorant Garamond / Playfair luxury serif + Plus Jakarta Sans
- **Icons**: Lucide React
- **Design System**: Deep obsidian dark mode (`#08090C`), warm champagne gold (`#D4AF37`), restro flame amber (`#FF7A3D`), and patisserie rose (`#E5989B`).

## 🏃 Running the Application

### Development Server
```bash
npm run dev
```

### Production Build & Launch
```bash
npm run build
npm run start
```
The server runs locally at: `http://localhost:3000`
